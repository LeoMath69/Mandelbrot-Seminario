# Mandelbrot-Seminario

## Dimensión fractal en la geometría de estructuras naturales: conjunto de Mandelbrot

Este repositorio contiene los códigos computacionales y resultados experimentales desarrollados para el estudio del conjunto de Mandelbrot y la aproximación de su dimensión fractal mediante el método de conteo de cajas (Box Counting).

## Objetivo

Estudiar computacionalmente el conjunto de Mandelbrot, analizar su frontera y explorar la aproximación de su dimensión fractal mediante procedimientos numéricos.

## Metodología

El trabajo utiliza herramientas de programación para:

- Construir y visualizar el conjunto de Mandelbrot.
- Aplicar el método de Box Counting.
- Analizar el efecto del refinamiento de malla.
- Comparar resultados para diferentes números de iteraciones.
- Estudiar la convergencia de las aproximaciones numéricas.

## Código computacional

El cuaderno principal se encuentra en:

- `Mandelbrot_BoxCounting.ipynb`

Fue desarrollado en Google Colab y contiene los experimentos computacionales del proyecto.

## Herramientas utilizadas

- Python
- Google Colab
- NumPy
- Matplotlib

## Proyecto académico

Seminario universitario sobre dimensión fractal y geometría de estructuras naturales.
